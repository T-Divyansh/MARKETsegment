# Market Segmentation using Clustering

This project aims to segment customers based on their credit and purchasing behavior using unsupervised machine learning. It helps businesses identify distinct customer groups for targeted marketing strategies. A Streamlit web application is also included for real-time cluster prediction.

# Objective:

Segment customers into distinct market groups based on behavioral data.

Enable businesses to understand and target customer segments effectively.

Deploy a user-friendly web interface for real-time segment prediction.

# Dataset:

The sample Dataset summarizes the usage behavior of about 9000 active credit card holders during the last 6 months. The file is at a customer level with 18 behavioral variables

# Algorithm used:

 K-Means Clustering:
An unsupervised learning algorithm used to segment customers into different clusters based on their credit and purchasing behavior.

# Final Model:

The final K-Means model was saved using pickle and integrated into a Streamlit web app that allows real-time customer segment prediction with interactive visualizations.

# Tech Stack: 

Python (Pandas, NumPy, Scikit-learn, Seaborn, Matplotlib)

Streamlit for UI

Pickle for model serialization
